## 句型 1｜want / need / decide + to V
- 頁碼：課本 p.3 Grammar ①、習作 p.1 A
- 提示：want、need、decide 後面要接「to + 原形動詞」，例如 need to make。

| 題型 | 題目 | 答案 | 其他選項 | 提示（可不填） | 來源 |
|---|---|---|---|---|---|
| 選擇 | Leo needs ___ money. | to make | making / makes | | 自編 |
| 選擇 | He needed ___ new sneakers. | to buy | buying / buys | | 原題 |
| 選擇 | Leo decided ___ in a restaurant after school. | to work | working / works | | 原題 |
| 選擇 | Porky decided ___ more. | to exercise | exercising / exercises | | 原題 |
| 選擇 | "I need ___ some weight," said Porky. | to lose | losing / loses | | 原題 |
| 選擇 | Porky wanted ___ weight. | to lose | losing / lose | | 原題 |
| 選擇 | My sister wants ___ a new watch. | to buy | buying / buys | | 自編 |
| 選擇 | We decided ___ the piano every day. | to play | playing / plays | | 自編 |
| 挑正確 | | He needs to make money. | He needs making money. / He needs to making money. | | 原題 |
| 挑正確 | | Leo wanted to swim. | Leo wanted swimming. / Leo wanted to swimming. | 課本 p.6 A 第 1 題：want 後面接 to + 原形動詞。 | 原題 |
| 重組 | 他決定多運動。 | He / decided / to exercise / more. | | | 原題 |
| 重組 | 梅肚子餓了，所以她想吃冰淇淋。 | May / is / hungry, / so / she / wants / to eat / ice cream. | | 習作 p.3 D 第 4 題：want 後面接 to + 原形動詞。 | 原題 |

## 句型 2｜quit / keep / enjoy + Ving
- 頁碼：課本 p.3 Grammar ②、習作 p.1 A
- 提示：quit、keep、enjoy（還有 practice、finish）後面要接「動詞 + ing」。

| 題型 | 題目 | 答案 | 其他選項 | 提示（可不填） | 來源 |
|---|---|---|---|---|---|
| 選擇 | Can I quit ___ here? | working | to work / work | | 原題 |
| 選擇 | Porky enjoyed ___. | eating | to eat / eat | | 原題 |
| 選擇 | (Sigh!) Please quit ___. | exercising | to exercise / exercise | | 原題 |
| 選擇 | We enjoy ___ books. | reading | to read / read | 課本 p.6 A 第 2 題：enjoy 後面接 Ving。 | 原題 |
| 選擇 | Keep ___! You can do it! | running | to run / runs | | 自編 |
| 選擇 | She practiced ___. | singing | to sing / sing | 習作 p.1 A 第 6 題：practice 後面接 Ving。 | 原題 |
| 選擇 | I finished ___ my homework. | doing | to do / does | | 自編 |
| 選擇 | David enjoys ___ stamps. | collecting | to collect / collect | | 原題 |
| 選擇 | My mom enjoys ___. | cooking | to cook / cooks | | 原題 |
| 挑正確 | | Can Tom quit working here? | Can Tom quit to work here? / Can Tom quits working here? | 習作 p.1 A 第 7 題：quit 後面接 Ving；Can 後面的動詞用原形。 | 原題 |
| 挑正確 | | She practiced singing. | She practiced to sing. / She practice singing. | | 原題 |
| 挑正確 | | My mom enjoys cooking. | My sister enjoys to swim. / My classmates enjoys running. | 習作 p.1 A 第 3 題：enjoy 後面接 Ving；classmates 是很多人，動詞不加 s。 | 原題 |
| 重組 | 湯姆和他的朋友喜歡打網球。 | Tom and his friend / enjoy / playing / tennis. | | 習作 p.3 D 第 2 題。 | 原題 |

- 頁碼：課本 p.3 Grammar ③、習作 p.1 A

| 選擇 | Leo loves ___. | to run | run / ran | | 原題 |

| 選擇 | Porky started ___. | exercising | exercise / exercised | | 原題 |
| 選擇 | He hates ___ in a restaurant. | to work | work / works | | 原題 |

## 句型 4｜Ving / To V 當主詞
- 頁碼：課本 p.3 Grammar ④、習作 p.1 A
- 提示：放在句子最前面當主詞時，要用「動詞 + ing」或「To + 原形動詞」，後面接 is。

| 題型 | 題目 | 答案 | 其他選項 | 提示（可不填） | 來源 |
|---|---|---|---|---|---|
| 選擇 | ___ money is never easy. | Making | Make / Makes | | 原題 |
| 選擇 | ___ weight is never easy. | Losing | Lose / Loses | | 原題 |
| 選擇 | ___ a movie is fun. | Watching | Watch / Watches | | 原題 |
| 選擇 | To ___ weight is never easy. | lose | losing / loses | | 原題 |
| 選擇 | ___ money is never easy. | To make | Make / To making | | 原題 |
| 選擇 | Playing basketball ___ my favorite. | is | are / do | | 原題 |
| 選擇 | Reading ___ my favorite. | is | are / am | | 原題 |
| 選擇 | Losing weight ___ not easy. | is | are / does | 課本 p.6 A 第 5 題。 | 原題 |
| 挑正確 | | Losing weight is never easy. | Lose weight is never easy. / Losing weight are never easy. | 習作 p.1 A 第 4 題。 | 原題 |
| 挑正確 | | To make money is never easy. | Making money does not easy. / To make money does never easy. | 習作 p.1 A 第 8 題：主詞後面用 is，不是 does。 | 原題 |
| 挑正確 | | Watching a movie is fun. | Watch a movie is fun. / Watching a movie are fun. | | 原題 |
| 重組 | 賺錢從來都不容易。 | Making money / is / never / easy. | | | 原題 |

## 閱讀｜Whale Swallowing Accident
- 頁碼：習作 p.4 E Reading Pick
- 提示：按「看文章」，再讀一次文章找答案。

> **Whale Swallowing Accident**
> Something surprising happened in June, 2021. A humpback whale swallowed a lobster diver in Massachusetts, USA. Lucky for the diver, forty seconds later, the whale found the diver wasn't yummy food and spat him back out. Experts said that was an accident because the whale couldn't see the diver while its mouth was open wide to eat small fish.
