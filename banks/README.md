# 題庫寫法說明

網站每次打開練習時，會直接讀這個資料夾裡的 `unit-1.md`、`unit-2.md`、`unit-3.md`，隨機抽題。
**改了 .md 就等於改了網站的題目**（不需要再改程式）。改完請 Claude 幫忙檢查格式和答案。

## 一個單元的結構

```
# Unit 1 What Can I Do              ← 單元名稱（首頁卡片會顯示）

## 句型 1｜want / need / decide + to V   ← 一個「## 」就是一個句型（一組題目）
- 頁碼：課本 p.3 Grammar ①、習作 p.1 A    ← 答錯時告訴孩子回去翻哪一頁
- 提示：want、need、decide 後面接「to + 原形動詞」。   ← 答錯時的提示

> 文章內容（閱讀題才需要）：用「> 」開頭，答題時可以按「看文章」打開

| 題型 | 題目 | 答案 | 其他選項 | 提示（可不填） |
|---|---|---|---|---|
| 選擇 | Leo needs ___ money. | to make | making / make | |
```

- 「頁碼」「提示」寫在每個句型的表格上面；某一題需要特別的提示，就填在表格最後一欄（會取代上面的「提示」）。
- 表格裡不能出現直線符號「|」。選項之間用「 / 」（前後有空格）分開。
- 每次練習會從各句型平均抽題，**每回 15 題**；同一回裡同一題不會重複出現。
- 想暫時拿掉一題：在那一行最前面加 `<!--`、最後面加 `-->`，或直接刪掉那一行。

## 題型

| 題型 | 題目欄 | 答案欄 | 其他選項欄 | 網站上怎麼出 |
|---|---|---|---|---|
| 選擇 | 句子，空格寫 `___` | 正確答案 | 2～3 個錯的選項 | 選出填進空格的字；沒有 `___` 就是一般問答選擇題 |
| 挑正確 | （可空白，或寫中文說明） | 正確的句子 | 錯的句子 | 「哪一句是對的？」 |
| 重組 | （可空白，或寫中文意思） | 照正確順序，用 ` / ` 切成字卡 | （空白） | 打亂字卡，照順序點 |
| 拼字 | 中文意思 | 英文單字或片語 | （空白） | 打亂字母（多 2 個不用的字母），照順序點 |
| 是非 | 一句敘述 | `對` 或 `錯` | （空白） | 對／錯 |
| 聽單字 | 要念的英文 | 正確答案 | 錯的選項 | 只念不顯示，「是哪一個單字？」 |
| 聽句子 | 要念的英文 | 正確答案 | 錯的選項 | 「你聽到哪一句？」 |
| 聽意思 | 要念的英文 | 中文意思 | 錯的中文意思 | 「這句話是什麼意思？」 |
| 聽數字 | 要念的英文 | 數字（例如 $148） | 錯的數字 | 「是多少？」 |
| 聽問答 | 要念的問句 | 最好的回答 | 錯的回答 | 「選出最好的回答」 |

- 題型是「聽」開頭的題目，只會出現在「聽力練習」，不會出現在「句型練習」。
- 聽力題用平板內建的英文語音朗讀（沒有 CD 音檔）。
